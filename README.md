# personal-site

My personal website.

Built with the help of AI.

## Tech Stack

- **Astro**, server-rendered, with MDX for posts
- Plain scoped CSS
- **TypeScript**
- **Cloudflare Workers** for hosting

## Running Locally

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```

## Content

- Blog posts are MDX files in `src/content/posts/`
- Recommendations live in `src/data/recommendations.ts`
- Monthly reviews live in `src/data/months.ts`
- Projects live in `src/data/projects.ts`

## Fonts

JetBrains Mono and Libron are self-hosted under `public/fonts/`. Both are under the SIL Open Font License.
